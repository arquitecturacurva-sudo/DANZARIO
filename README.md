# DANZARIO
Browser-based class planning tool for dance teachers — choreography tracking, monthly cycles, student attendance and feedback, service templates, and emotional tracker. Built as a single HTML file.

A browser-based planning tool built for dance teachers who want to 
organize their classes with intention — and not forget to take care 
of themselves in the process.

## What it does

- **Processes** — monthly choreography cycles with shared progress tracking
- **Services** — define your own (monthly program, private class, drop-in, etc.)
- **Cycles** — per-student attendance stats, evaluation criteria, and feedback
- **Class planner** — time-block itinerary, warmup, dynamics, emotional tracker
- **Free classes** — register one-off sessions and mark them as done
- **Fully offline** — runs as a single HTML file, no server needed

## Stack

Single `index.html` — React 18 (via CDN), Babel standalone, localStorage persistence.
No build step. Open in browser and go.

## Status

Prototype stage — built iteratively from a real teacher's workflow.
